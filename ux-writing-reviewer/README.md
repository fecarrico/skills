# UX Writing Reviewer Skill - Sem Parar

Esta skill foi atualizada para atuar especificamente como **UX Writer do Sem Parar**, otimizada para a revisão de conteúdos de FAQ.

## Como Usar

Para realizar uma revisão em uma planilha de FAQ (seguindo o padrão Sem Parar), peça no chat:

> "Antigravity, use a skill de UX Writing no arquivo `planilha_faq.xlsx` na coluna `E`"

O Antigravity seguirá automaticamente o novo manual ([ux_writing_review_manual.md](./ux_writing_review_manual.md)) e aplicará as diretrizes de tom de voz, vocabulário e clareza da marca.

## Destaques da Versão Sem Parar
- **Zero Supressão**: Foco total na preservação de links, dados técnicos e orientações de especialistas. Lapidar não é resumir.
- **Tom de Voz**: Humano, direto e sem burocracia.
- **Vocabulário**: Padronização de termos ("carro", "SuperApp Sem Parar", "tag").
- **Foco em FAQ**: Melhoria de escaneabilidade e preservação do cerne da informação.
- **Saída Estruturada**: Inclui o texto revisado e a justificativa curta (ex: "Ajuste de tom").
